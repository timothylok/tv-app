# AI Channels - user manual

Open **AI Channels** from the Android TV home screen. It tunes to the channel you watched last and joins the programme already on air, like live TV. Nothing to choose, nothing to download.

## Remote keys
| Key | What it does |
|---|---|
| Channel up / Channel down | Next / previous channel (wraps around) |
| D-pad up / down | Same as channel up / down |
| Number keys | Type a channel number (for example 1); it switches after a moment, or press OK |
| OK | Show what is on now and what is next, plus a small line with when the channel was last updated (New Zealand time), the latest episode id and how much of the free AI allowance is left (hides after 5 seconds) |
| Back | Open the channel list; Back again closes it. Pick a channel with up/down and OK |
| Home | Leave the app; sound stops |

Between episodes you see a "next episode coming up shortly" screen, then the next one starts by itself.
